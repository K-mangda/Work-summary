# ข้อความสั่งสำเร็จรูป (วางในแชทของแต่ละโปรเจกต์)

ใช้ตอนจบงานในแชทที่ทำงานจริง copy ข้อความในกรอบด้านล่างไปวาง แล้วนำผลลัพธ์ที่ได้ไปวางในแชท Work-summary พร้อมพิมพ์นำว่า "บันทึกลงเว็บวันนี้:"

```text
สรุปงานที่ทำในแชทนี้ตามรูปแบบด้านล่าง เพื่อนำไปบันทึกในเว็บสรุปงาน

กฎ:
- เขียนเป็นภาษางานแบบมืออาชีพ ห้ามมีคำสั่งหรือคำที่บอกให้ AI ทำอะไร ห้ามพูดถึง AI หรือแชท
- เขียนเฉพาะสิ่งที่ทำจริงในแชทนี้ ห้ามเดาหรือแต่งเพิ่ม
- ช่อง "ตรวจแล้ว" ตอบ "ใช่" ได้ก็ต่อเมื่อตรวจจริงในแชทนี้ (รันแล้ว เปิดดูแล้ว หรืออ่านโค้ดแล้ว) และบอกวิธีที่ตรวจ ถ้าไม่ได้ตรวจให้ตอบ "ไม่"
- ถ้างานมีหัวข้อย่อยหลายข้อ ให้แตกเป็นรายการหัวข้อย่อย
- ใช้ชื่อโปรเจกต์และหมวดย่อยให้สะกดเหมือนกันทุกครั้ง

รูปแบบ:

## รายงานงาน วันที่ <YYYY-MM-DD>
โปรเจกต์: <ชื่อโปรเจกต์ เช่น Blog หรือ OnesiamFactory>
หมวดย่อย: <เช่น Backoffice หรือ Frontend ถ้าไม่มีให้ใส่ ->

### งาน: <ชื่องาน>
- สถานะ: <todo | doing | done | blocked>
- ตรวจแล้ว: <ใช่ (ตรวจอย่างไร) | ไม่>
- ผลลัพธ์: <สิ่งที่เปลี่ยนหรือที่ได้>
- หมายเหตุ: <ปัญหาหรือข้อสังเกต ถ้าไม่มีใส่ ->
- หัวข้อย่อย:
  - [x] <หัวข้อย่อยที่เสร็จ>
  - [ ] <หัวข้อย่อยที่ยังไม่เสร็จ>
- ลิงก์หรือไฟล์ที่เกี่ยวข้อง: <ถ้ามี>
- ภาพก่อน-หลัง: <มี (ไฟล์ไหน) | ไม่มี>

(ซ้ำบล็อก "### งาน" ตามจำนวนงาน)
```

## หมายเหตุ
- ภาพก่อน-หลัง: ส่งไฟล์รูปแนบมาในแชท Work-summary พร้อมข้อความรายงาน
- ถ้าวันเดียวกันมีหลายโปรเจกต์ ให้วางรายงานทีละโปรเจกต์ได้เลย ระบบจะรวมเข้าวันเดียวกัน
